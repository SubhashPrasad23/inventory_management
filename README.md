# Smart Dukan - AI Inventory Management

A full-stack inventory management system built for Indian retailers and wholesalers.

## Features
- AI-powered business insights (Google Gemini)
- Real-time dashboard with analytics
- Billing with PDF invoice generation
- Barcode scanning (camera + barcode scanner gun)
- Stock predictions & low-stock alerts
- JWT authentication 

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Zustand, Recharts
- **Backend:** Node.js, Express, MongoDB, Mongoose
- **AI:** Google Gemini API
- **PDF:** PDFKit
